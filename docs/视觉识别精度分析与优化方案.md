# 视觉识别精度分析与优化方案

本报告基于当前源码、4 张已有人工标注样例和 4 张实际报文触发照片的离线复跑。未修改算法、模型权重或运行配置。诊断输出保存在本次分析的 visualization 目录，不写入生产读数或厂家缓存。

## 当前流程

厂家新报文入本机缓存 → 按厂家平台接收时间选择历史 JPEG → 单帧增强识别 → 刻度与指针两个 YOLO 关键点模型 → 圆心/半径融合 → 依赖初步定位裁图放大后再次推理 → 图像法寻找 0/16 刻度线（失败回退模型点）→ 细暗线径向扫描选择针角（证据不足回退模型针尖）→ 角度线性映射 0～16 → 两级线性标定 → 两位小数 → 可靠性状态 → 按原报文编号比较与展示。

当前摄像头为 640×360 子码流，缓存 120 秒、2 帧/秒、64 MB 上限。报文模式调用 read_one，虽然 read.burst 为 5，但没有调用 read_one_multi，所以当前是单帧结果。

## 实测证据

现有人工标注数字仅用作样例标签，不视为可溯源标准。此前用户要求识别数值不变、单位解释为 MPa，本报告沿用这一约定。

| 样例 | 人工标签 | 算法结果 | 算法减标签 |
|---|---:|---:|---:|
| 1.jpg | 7.50 | 7.76 | +0.26 |
| 2.jpg | 5.45 | 5.32 | -0.13 |
| 3.jpg | 8.60 | 8.72 | +0.12 |
| 4.jpg | 4.00 | 3.81 | -0.19 |

上述 4 张 MAE 约 0.175 MPa、RMSE 约 0.184 MPa、最大绝对差 0.26 MPa。样本很少，且不是独立新测试集，不能据此宣称真实系统精度。

实测照片 report_1792491041527844.jpg 重现“跨度异常 32°”。report_1792491101459027.jpg 重现 2.27 MPa，但圆心为 (321.1,214.7)，标注圆位于桌面，实际表盘在画面左上。整幅图被模型误判为目标区域，后续裁图围绕错误中心进行，图像法又对桌面边缘得到 74% 的所谓证据，结果却没有 flag。这是找错对象后仍输出成功，不是单纯数值偏差。

另两张近距离照片复跑结果为 3.76 和 3.51 MPa，均回退到模型刻度点，没有稳定采用实际 0/16 刻度线。3.76 那张的图像法与模型针尖相差 16°，也仅留备注。没有对应独立真值，不能判断哪个数准确。

## 优先级与实施方案

### 第一阶段 固定表盘区域与质量门槛

摄像头固定安装并尽量正对表盘，减少反光、遮挡及运动模糊。优先增加表盘真实像素，建议先试验表盘直径至少 400～600 像素，作为工程目标而非普适保证。评估主码流时必须先裁真实表盘 ROI 再送入 640 输入模型，否则整图缩小会抵消分辨率收益；同时重新测量 CPU 延迟和缓存实际覆盖时长，64 MB 上限可能让高清缓存短于 120 秒。

固定相机先提供人工框选 ROI，一次选择后保存。模型与图像法都只能在 ROI 内寻找目标。检验圆心是否在表盘内、半径与边界是否合理、关键点顺序与置信度是否有效、两模型是否对应同一表盘、刻度是否具备合理结构。没有几何支撑时不输出可信成功读数。

Hough 圆心与关键点交点目前在分歧大时优先取交点；应改为结合真实表盘边界和轴心的约束判断。单独提高 conf 或信任针尖置信度不能排除找错表盘。

### 第二阶段 几何与刻度标定

先矫正明显倾斜。固定机位可人工确定已知表面对应点，进行透视变换；必要时先完成镜头畸变标定。不能仅把任意椭圆拉成圆就宣称几何角度正确。

对固定表型保存圆心、实际零刻度线、满量程刻度线及中间主刻度。使用真实刻度线，不把数字字符中心当角度基准。先建立固定模板对照，再评估自动检测。若中间刻度显示非线性或仍有透视残差，可采用经过独立验证的分段角度映射，不能用一条回归线掩盖定位错误。

指针优先在正确表盘和合理半径范围内提取细长线，再用多点线拟合估计方向，排除文字、配重块和外框。现有扫描以 1° 为网格，对约 270°/16 MPa 的表，1° 对应约 0.059 MPa；可在候选峰附近细化角度并拟合针身，不必整体高密度扫描。细化采样仍不能恢复模糊图缺失的信息。

### 第三阶段 每报文一次最终结果 加入邻帧校验

保持报文触发机制，从目标时间附近约 ±0.5～1 秒内选择 3～5 张缓存帧，优先时间最近且清晰、反光少的画面。2 fps 下 ±1 秒通常只有约 4～5 帧，不足时明确降级。

每组只输出一条最终记录，附代表帧、各帧时间、最大时间差、帧间角度离散度。稳定压力可使用稳健聚合；若出现多个方向簇或压力确实快速变化，应复核或使用最接近目标时刻的可靠单帧，不能通过平均制造不存在的瞬时压力。

目前多帧参数 ANG_TOL=12° 和 MULTI_SPREAD_FLAG=0.8 对精度研究偏宽，需按目标误差预算重新验证。多帧能够减小随机波动，不能修复全组找错目标或共同偏置。

### 第四阶段 数据集与独立验证

建立当前相机、当前表型的独立标注集，覆盖低中高压力、正反行程、不同时间及清晰度。起步可选 8～10 个安全可达稳定压力点，每点记录 20～30 组；这些是样本计划，不是统计充分性的保证。不要求现场为了采样超出安全操作范围。

视觉算法的真值应是同一张表盘的可靠人工读数或更精确的图像几何标注；变送器读数只用于系统对照，不能直接替代机械表盘本身的示值，否则会把机械表误差也拟合进视觉算法。若用于计量精度声明，还需独立参考设备与相应的不确定度依据。

按采集批次和时间划分调参与测试，不能把相邻帧随机拆到两边。保留失败、缺图与需复核样本，分别报告成功率、错误接受率、MAE、RMSE、P95、最大误差、静态重复性和时延。

建议初始研究目标可以讨论为 MAE≤0.10 MPa、P95≤0.20 MPa；应待新标注集建立后确认可达性，当前不能承诺。机械表的 2.5 级报警阈值与视觉质量判据分开使用。

## 代码中需专门复核的细节

- 2026-10-22 已修复高清摄像头的大图误委托：摄像头单帧及连拍调用显式传入 allow_legacy=False，始终进行增强定位，不再仅因 raw_d≥700 像素切回原工具。旧离线照片保留原调用行为。当天 7 张高清图旧结果为 2.57～2.94 MPa，修复后离线复算为 3.63～4.18 MPa；用户口述约 3.8 仅是粗略参考，不能据此把这 7 张均当作 3.8 的精确真值或宣布精度合格。
- _measure 中“选择模型针尖后，若 diff>25 再转图像兜底”的分支，diff 在选择模型时已为 0，正常路径下难以触发；应保留独立的扫描与模型分歧变量后再决策。
- 模型针尖与图像扫描明显不一致，在当前证据门槛下仍可能标 ok。应先加入几何和候选唯一性约束，再用新数据确定接受/复核阈值，不能简单一律拒绝或永远优先某一方法。
- 原始 CAL_A=0.9934、CAL_B=0.2064 来自旧样本；CAL2 仍是 1/0。ROI、几何和刻度修复后再重新评估标定，不把旧系数当作当前设备的准确保证。
- tests/check_reading.py 比较的是旧输出是否不变，不是比较人工真值。它是回归检查，不能证明读数准确。
- 增强层返回圆心、半径、刻度角、针角、证据等诊断字段，但流水线成行时多数未保存。后续应保留这些字段和可视化覆盖图，方便定位错误。
- 计算过程中保留原始角度和未舍入值，最终展示时再舍入；显示更多小数不代表精度提高。

## 推荐下一步

先做固定 ROI、几何质量门槛和覆盖图，再做主码流 ROI 对照、刻度模板与针线精修，之后加入报文邻帧聚合，最后做标定和独立测试。只有上述步骤仍不足时，再针对当前相机和表型重新标注、微调两个关键点模型。
