# 压力表视觉识别与变送器比对系统

当前工作目录为 `D:\压力表系统当前完整源码`。当前系统采用厂家 HTTP 直连、新报文触发识别和历史画面缓存，压力统一使用 MPa。

## 日常使用

1. 双击 `启动前端.bat`，打开 http://localhost:8787/ 并登录。
2. 在页面点击“启动采集”。系统启动单个摄像头进程，持续缓存画面，收到新变送器报文后识别对应历史画面。
3. “暂停采集”暂停本机查询与识别；变送器仍按设备自身周期上传。“冻结展示”只冻结页面。
4. “一键清除”开始新一轮研究，先备份，保留原始照片、记录文件和配置。
5. `停止研究采集.cmd` 安全关闭摄像头进程。正常使用页面启动按钮即可，不要反复双击启动流水线。

当前变送器目标周期为 60 秒，本机每 20 秒查询厂家；摄像头使用主码流（实测 2560×1440），视频缓存保留最近 120 秒，每秒 2 帧，最多 256 MB。报文编号绑定识别结果，相同报文不重复生成结果。缺少历史画面时明确标记，不用当前照片补值。

摄像头安装与清晰度调整见 [摄像头布置与高清取流](docs/摄像头布置与高清取流.md)。

目前按厂家平台接收时间选帧，属于近似同步，不代表设备实际采集时刻严格同步。对应画面和时间差可在前端查看。

| models | 刻度、指针两个模型；文件名保留兼容，不代表当前显示单位 |

| tests | 自动化检查与隔离回归测试，后续升级时继续使用 |

| docs | 当前方案说明及文件整理记录 |

## 主要代码与配置

- 厂家登录、token、增量查询：`src/data_sync/vendor_http_source.js`。
- 历史画面缓存：`src/camera/read_camera.py`。
- 报文触发识别：`src/pipeline/triggered_capture.py`。
- 报文绑定、时间差及误差：`src/data_sync/time_comparison.js`。
- 页面与研究图表：`web/js/live.js`、`web/js/research.js`、`web/css/live.css`。
- 厂家地址、项目 ID、设备编号：`config/transmitter.json`。
- 厂家查询凭据：`config/vendor-credentials.local.json`，不要公开分享。
- 摄像头、缓存参数：`config/pipeline.json`。当前 `read.trigger_mode` 为 `transmitter`，不再独立定时识别。
- 量程、单位与选帧容差：`config/live.json`。
- Python：`config/python_path.txt`，指向本机 Anaconda 的 pressure 环境；该识别环境不在项目文件夹中，迁移电脑时需重新配置。

详细说明见 `docs/分钟级同步研究.md`。旧 API 的 valueKpa 等字段保留兼容，当前研究读数由 meter.unit 指定为 MPa。

## 辅助入口

`启动流水线.bat` 可手动运行采集；`预演看计划.bat` 查看当前模式；`读图片.bat` 用于离线图片验证；`标定.bat` 用于人工真值标定；`仅摄像头抓图.bat` 用于单独排查摄像头；`检查项目.bat` 检查基础依赖；`配置厂家直连.cmd` 配置厂家查询账号。
